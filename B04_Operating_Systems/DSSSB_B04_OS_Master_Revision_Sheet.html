3. Convoy Effect occurs in FCFS when short I/O-bound jobs queue behind a long CPU-bound job.
4. Aging is the standard technique to prevent starvation in priority scheduling.
5. A thread shares code, data, heap, and open files with peer threads of the same process.

14. Belady's Anomaly: increasing physical frames leads to an increase in page faults in FIFO.

16. The Working Set Model prevents thrashing by ensuring Σ W_i <= Total Available Frames.
17. An Inode stores all file metadata and block pointers, but NOT the file name (stored in directory).
18. Shortest Seek Time First (SSTF) disk scheduling can cause starvation for distant tracks.
