Asymptotic Notations (O, Ω, Θ), Growth Rates & Master Theorem

Formal mathematical definitions, growth order hierarchy, and all 3 cases of the Master Theorem.

Big-O (Upper Bound)

0 <= f(n) <= c * g(n)

Guarantees algorithm will not exceed this rate in the worst case.

Big-Ω (Lower Bound)

0 <= c * g(n) <= f(n)

Greedy Algorithms

• Makes local optimum choice at each step without backtracking.
• Fractional Knapsack: Greedy by value-to-weight ratio (v/w) is optimal. Running time O(n log n).

• Huffman Coding: Builds optimal prefix-free tree in O(n log n) using min-heap.

Dynamic Programming

• Requires Optimal Substructure + Overlapping Subproblems.
• 0/1 Knapsack: Solved in O(n * W) pseudo-polynomial time.
• LCS (Longest Common Subsequence): Recurrence: match = 1 + dp[i-1][j-1]; mismatch = max(dp[i-1][j], dp[i][j-1]). Running time O(m * n).
• Matrix Chain Multiplication: Solved in O(n^3) time and O(n^2) space.

Complexity Classes Breakdown

• P: Decision problems solvable in deterministic polynomial time O(n^k).
• NP: Decision problems verifiable in polynomial time (solvable by non-deterministic machine).
• NP-Hard: Every problem in NP is polynomial-time reducible to it (at least as hard as any problem in NP).
• NP-Complete: In NP AND NP-Hard. Hardest problems in NP (e.g., 3-SAT, TSP, Vertex Cover, Hamiltonian Cycle).

Backtracking vs Branch & Bound

• Backtracking: Depth-First Search (DFS) on state-space tree. Prunes branches as soon as constraints are violated. Used for decision and satisfaction problems (8-Queens, N-Queens, Sudoku).
• Branch & Bound: Breadth-First Search (BFS) or Best-First Search with Priority Queue. Computes lower/upper cost bounds to prune non-optimal paths in optimization problems (Traveling Salesperson, 0/1 Knapsack).
