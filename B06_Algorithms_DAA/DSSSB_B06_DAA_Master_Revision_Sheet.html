Algorithms (DAA) — 30 Golden Formulas & Complexity Cheat Sheet

Master theorem formulas, comparison sort lower bounds, greedy selection criteria, DP recurrences, and NP-completeness checklist.

Master: Case 2 Equality

If f(n) = Θ(n^(log_b a)): T(n) = Θ(n^(log_b a) * log n).
E.g., Merge sort 2T(n/2)+n ➔ Θ(n log n).

Sort: Decision Tree Bound

Lower bound for comparison-based sorting is strictly Ω(n log n) in worst case (log2(n!) = Ω(n log n)).

Heap: Build-Heap Time

Building a Max-Heap bottom-up takes strictly O(n) linear time (not O(n log n)).

Knapsack: Greedy vs DP

Fractional: Greedy by v/w ratio is optimal: O(n log n).
0/1 Knapsack: DP table: O(n * W).

DP: Matrix Chain Multi

Time complexity = O(n^3).
Space complexity = O(n^2).

MST: Edge Count Rule

Any Spanning Tree on V vertices always contains exactly V - 1 edges.

Dijkstra: Negative Fail

Dijkstra FAILS with negative edge weights. Use Bellman-Ford O(V*E) instead.

Graph: Topological Sort

Topological sort is possible IF AND ONLY IF the graph is a Directed Acyclic Graph (DAG).

Complexity: NP-Complete

X is NP-Complete if: X is in NP AND X is NP-Hard.
First proven: SAT (Cook's Theorem 1971).

20 Golden Exam One-Liners (Quick Revision)

1. Big-O represents an asymptotic upper bound; Big-Ω represents a lower bound; Big-Θ represents a tight bound.
2. Asymptotic hierarchy: 1 < log n < √n < n < n log n < n^2 < 2^n < n!.
3. Binary search requires a sorted array and runs in strictly O(log n) time.
4. Merge Sort is strictly O(n log n) in Best, Average, and Worst cases, requiring O(n) auxiliary space (Stable).
5. Quick Sort average time is O(n log n), but worst-case degrades to O(n^2) when partitions are maximally unbalanced.
6. Insertion Sort runs in O(n) linear time when input array is already sorted or nearly sorted.
7. Strassen's matrix multiplication reduces multiplications from 8 to 7, running in O(n^2.807) time.
8. Finding simultaneous min and max takes exactly ⌈3n/2⌉ - 2 comparisons by pairing elements.
9. Counting Sort and Radix Sort achieve linear time by avoiding pairwise comparisons.
10. Activity Selection sorts jobs by earliest Finish Time to maximize compatible jobs in O(n log n).
11. Huffman coding builds a full binary tree with prefix-free codes in O(n log n) using a min-heap.
12. Dynamic Programming requires two conditions: Optimal Substructure and Overlapping Subproblems.
13. 0/1 Knapsack runs in O(n * W) pseudo-polynomial time using bottom-up tabulation.
14. Longest Common Subsequence (LCS) runs in O(m * n) time using dynamic programming.
15. Floyd-Warshall computes All-Pairs Shortest Paths in O(V^3) time and detects negative cycles.
16. BFS uses a FIFO Queue (O(V+E)); DFS uses a LIFO Stack (O(V+E)).
17. Kruskal's algorithm uses Disjoint Set Union (DSU) with path compression to detect cycles in O(E log E).
18. Bellman-Ford runs in O(V * E) time, relaxing edges V - 1 times, and handles negative weights.
19. NP means Nondeterministic Polynomial time (verifiable in polynomial time), NOT non-polynomial.
20. Backtracking uses Depth-First Search (DFS) with bounding functions to prune non-viable subtrees early.
