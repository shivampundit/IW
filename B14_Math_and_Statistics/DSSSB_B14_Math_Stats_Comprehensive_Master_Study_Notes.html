Counting Formulas on Set of Size n
• Power Set Size: 2^n elements
• Total Binary Relations: 2^(n^2) relations
• Reflexive Relations: 2^(n^2 - n) relations
• Symmetric Relations: 2^(n(n + 1) / 2) relations

Relation Classifications

• Equivalence Relation: Reflexive, Symmetric, and Transitive (partitions set into disjoint equivalence classes).
• Partial Order (Poset): Reflexive, Anti-symmetric, and Transitive (visualized via Hasse Diagram omitting self-loops and transitive edges).
• Lattice: A Poset where every pair {a, b} has unique Least Upper Bound (Join ∨) and Greatest Lower Bound (Meet ∧).

Probability Axioms & Bayes
• Conditional: P(A | B) = P(A ∩ B) / P(B)

• Bayes' Theorem:
P(Ai | B) = [P(B | Ai) * P(Ai)] / Σ [P(B | Aj) * P(Aj)]
Expectation & Variance

• Expectation: E(X) = μ = Σ [x_i * P(x_i)]. Linear: E(aX+b) = aE(X)+b.
• Variance: Var(X) = σ^2 = E(X^2) - [E(X)]^2.
• Scaling: Var(aX + b) = a^2 * Var(X). Standard deviation σ = √Var(X).

Numerical Methods: Newton-Raphson, Bisection & Quadrature

Order of convergence, Newton-Raphson formula, Trapezoidal rule, and Simpson's 1/3 and 3/8 rules.

Root Finding Iterations
• Bisection Method: Halves bracket if f(a)*f(b) < 0. Order of convergence = 1 (Linear). Guaranteed convergence.
• Newton-Raphson: x_(n+1) = x_n - f(x_n) / f'(x_n). Order of convergence = 2 (Quadratic)! Fails if f'(x)=0.
• Secant Method: Order = 1.62 (Superlinear, golden ratio).
Numerical Integration (Quadrature)
• Trapezoidal Rule: (h/2) * [ (ends) + 2*(all middle) ]. Error O(h^2).
• Simpson's 1/3 Rule: (h/3) * [ (ends) + 4*(odds) + 2*(evens) ]. Requires n to be an EVEN number! Error O(h^4).
• Simpson's 3/8 Rule: Requires n to be a multiple of 3.
• Runge-Kutta 4th Order (RK4): Solves ODEs with O(h^4) accuracy.
