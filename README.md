# DSSSB TGT Computer Science (2026 Edition) — Complete 20-Subject Multi-Page Master Portal

## 🚀 GitHub Pages Instant Deployment Guide
1. Extract this ZIP archive into your GitHub repository root folder.
2. Commit and push all files and the 20 subject folders (`index.html`, `.nojekyll`, `A1_General_Awareness/` ... `B15_Physics_of_Computing/`) to your `main` branch.
3. Go to **Settings → Pages → Build and deployment**, select **Deploy from a branch (`main` / `/root`)**, and click **Save**.
