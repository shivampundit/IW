# DSSSB TGT Computer Science Preparation Portal

A complete, interactive preparation portal for the DSSSB TGT Computer Science Examination (200 Marks Total).

## Features
- **1,000 Questions**: 50 authentic MCQs per subject across all 20 subjects (Section A + Section B).
- **Interactive Practice**: Instant answer verification, detailed bilingual explanations, and real-time score tracking (+1.00 / -0.25 negative marking).
- **Comprehensive Notes**: 475,000+ characters of textbook-level study notes across 130+ topics.
- **Master Revision Sheets**: 20 rapid formula sheets with 600+ golden exam one-liners.

## How to Deploy on GitHub Pages

1. **Create a GitHub Repository**:
   - Go to [GitHub](https://github.com) and create a new repository (e.g., `dsssb-tgt-cs-portal`).
   - Set the repository to **Public**.

2. **Upload Files**:
   - Upload `index.html`, `README.md`, and `.nojekyll` directly into the repository's root directory (`main` branch).

3. **Enable GitHub Pages**:
   - In your repository, click on **Settings** (gear icon).
   - In the left sidebar, click on **Pages**.
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Select branch: **main** and folder: **/ (root)**.
   - Click **Save**.

4. **Access Your Live Website**:
   - Wait 1-2 minutes. Your portal will be live at:
     `https://<your-username>.github.io/<repository-name>/`
