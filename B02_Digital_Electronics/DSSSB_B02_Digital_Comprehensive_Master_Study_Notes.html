Number Systems, Binary Arithmetic & Error Codes

Radix conversions, 1's and 2's complement ranges, signed overflow arithmetic, Gray codes and Hamming error correction.

Radix / Bases

• Binary (r=2): Digits 0, 1
• Octal (r=8): Digits 0–7 (Group 3 binary bits)
• Decimal (r=10): Digits 0–9
• Hexadecimal (r=16): 0–9, A–F (Group 4 binary bits)

Complements System

• r's complement = r^n - N
• (r-1)'s complement = (r^n - 1) - N
• 1's complement: Invert every bit (0➔1, 1➔0)
• 2's complement: 1's complement + 1

Representation Ranges (n-bit)

• Unsigned: 0 to (2^n - 1)
• Sign-Magnitude: -(2^(n-1)-1) to +(2^(n-1)-1)
• 1's Complement: -(2^(n-1)-1) to +(2^(n-1)-1)
• 2's Complement: -(2^(n-1)) to +(2^(n-1)-1)

⚡ Signed Arithmetic Overflow Detection Rule

In 2's complement arithmetic, an overflow occurs if the sum of two positive numbers yields a negative result, or two negative numbers yield a positive result. In hardware logic:

Overflow Flag (V) = C_(in) XOR C_(out) (Carry into sign bit XOR Carry out of sign bit)

If V = 1, arithmetic overflow has occurred and the result in the register is mathematically invalid.

Karnaugh Maps (K-Maps), Implicants & Minimization

Minterms/Maxterms, Prime Implicants, Essential Prime Implicants, Don't Care minimization, and 4-variable map rules.

Canonical Forms & Definitions

• Minterm (m_i): Product of all literals where output = 1. (m_5 for 3 vars ABC = A . B' . C = 101).
• Maxterm (M_i): Sum of all literals where output = 0. (M_5 = A' + B + C').
• Complementary Relation: m_i = (M_i)'.
• SOP (Sum of Products): ORing of minterms, Σm(...).
• POS (Product of Sums): ANDing of maxterms, ΠM(...).

Implicants Hierarchy

• Implicant: Any minterm or group of minterms where function = 1.
• Prime Implicant (PI): Maximal group of adjacent 1s that cannot be combined with any other group to eliminate further literals.
• Essential Prime Implicant (EPI): A PI that covers at least one '1' that is NOT covered by any other prime implicant. EPIs MUST be in the final minimal expression!
• Redundant PI: A PI whose 1s are already completely covered by other EPIs.

K-Map Variable Elimination Formula

In an n-variable K-map, grouping 2^k adjacent cells eliminates exactly k variables:

  • Pair (2^1 = 2 cells) ➔ Eliminates 1 variable
  • Quad (2^2 = 4 cells) ➔ Eliminates 2 variables
  • Octet (2^3 = 8 cells) ➔ Eliminates 3 variables
  • Hexadecimal (2^4 = 16 cells) ➔ Eliminates 4 variables (Output = 1 constant)

Multiplexers (MUX) & Decoders

• Multiplexer (2^n to 1): 2^n data inputs, n select lines, 1 output line. Acts as universal function generator.
• Demultiplexer (1 to 2^n): 1 input line, n select lines, 2^n output lines. Functionally identical to a Decoder with enable input.
• Decoder (n to 2^n): Converts n-bit binary code into one of 2^n active outputs.
• Priority Encoder: Generates binary code for the highest-priority active input line.

Counter Types & Timing Constraints

Asynchronous (Ripple): Clock applied only to FF0; subsequent FFs clocked by prior outputs. Total delay T = n * t_pd. Maximum clock: f_max = 1 / (n * t_pd).
Synchronous: All flip-flops clocked simultaneously by common clock. Much faster: f_max = 1 / (t_pd + t_comb).
MOD-N Counter: Number of FFs required = smallest integer n such that 2^n >= N. (e.g., MOD-12 requires 4 FFs).
Ring Counter (n FFs): Exactly n distinct states (circulates a single 1).
Johnson Counter (n FFs): Exactly 2n distinct states (inverted output feedback).

Shift Registers & 555 Timer Formulas

• Shift Register Modes: SISO (Serial-In Serial-Out: takes 2n-1 pulses), SIPO, PISO (takes n-1 pulses), PIPO (takes 1 pulse).
• 555 Astable Multivibrator (Free Running):
f = 1.44 / ((R_A + 2*R_B) * C)
Duty Cycle D = (R_A + R_B) / (R_A + 2*R_B) * 100% (Always > 50% in standard circuit).
• 555 Monostable Multivibrator (One-Shot):
Pulse Width W = 1.1 * R_A * C
