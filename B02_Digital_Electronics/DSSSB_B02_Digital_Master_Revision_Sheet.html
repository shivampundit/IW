Digital Electronics — 30 Golden Formulas & Circuit Cheat Sheet

Universal gate counts, K-map grouping laws, flip-flop excitation formulas, counter timing limits, and logic family rankings.

Gates: Universal Counts

XOR: 4 NAND or 5 NOR.
XNOR: 5 NAND or 4 NOR.
AND: 2 NAND or 3 NOR.
OR: 3 NAND or 2 NOR.

Arithmetic: 2's Complement

Range (n bits): -2^(n-1) to +(2^(n-1) - 1).
Signed Overflow: V = C_(in) XOR C_(out) of MSB.

Hamming: Error Correction

Condition: 2^p >= m + p + 1.
For m = 8 data bits, parity p = 4 bits (Total = 12 bits).

K-Map: Variable Elimination

Grouping 2^k cells eliminates k variables.
Pair = 1 var, Quad = 2 vars, Octet = 3 vars eliminated.

Adder: Full Adder Equation

Sum = A XOR B XOR C_in.
Carry = AB + BC_in + AC_in.
Requires 2 Half Adders + 1 OR gate.

MUX: Tree Expansion

To build 16-to-1 MUX from 4-to-1: Stage 1 = 16/4 = 4; Stage 2 = 4/4 = 1. Total = 5 MUXes.

Flip-Flop: Characteristics

JK: Q_(n+1) = JQ' + K'Q.
D: Q_(n+1) = D.
T: Q_(n+1) = T XOR Q.
SR: S=1, R=1 is Invalid!

Counters: Ripple vs Ring

Ripple f_max: 1 / (n * t_pd).
Ring (n FFs): n states.
Johnson (n FFs): 2n states.

Families: Speed & Power

Fastest: ECL (~1 ns).
Lowest Power: CMOS (~nW).
Highest Fan-Out: CMOS (>50).
Highest Noise Margin: CMOS.

20 Golden Exam One-Liners (Quick Revision)

1. NAND and NOR are called Universal Gates because any Boolean function can be implemented using them alone.
2. Number of self-dual Boolean functions of n variables is 2^(2^(n-1)).
3. Gray code is a Unit-Distance code because adjacent codewords differ by exactly 1 bit.
4. Excess-3 is a Self-Complementing code because its 9's complement is obtained by inverting bits.
5. De Morgan's laws: (A + B)' = A'B' and (AB)' = A' + B'.
6. An Essential Prime Implicant (EPI) covers at least one '1' not covered by any other prime implicant.
7. Don't cares (X) are included in K-map groups only if they help enlarge the group to eliminate literals.
8. Carry Lookahead Adder (CLA) computes carries in parallel using G_i = A_i*B_i and P_i = A_i XOR B_i.
9. A 2^n to 1 Multiplexer requires n select lines and acts as a universal function generator.
10. In level-triggered JK flip-flop, Race-Around Condition occurs when J=1, K=1 and clock pulse width t_p > t_pd.
11. Master-Slave JK flip-flop eliminates race-around by clocking Master on CLK=1 and Slave on CLK=0.
12. Setup time is minimum time data must be stable before clock edge; Hold time is time after clock edge.
13. A MOD-N counter requires n flip-flops such that 2^n >= N.
14. An n-bit Ring counter has n states; an n-bit Johnson counter has 2n states.
15. Serial-In Serial-Out (SISO) register requires n pulses to load and n-1 pulses to retrieve (Total 2n-1).
16. Astable multivibrator has 0 stable states (clock oscillator); Monostable has 1 stable state (one-shot).
17. 555 Timer astable frequency: f = 1.44 / ((R_A + 2*R_B) * C).
18. ECL (Emitter-Coupled Logic) is the fastest logic family because transistors operate in non-saturated mode.
19. CMOS features lowest static power dissipation and highest noise margin (V_DD / 2).
20. Speed-Power Product (SPP) = Propagation Delay * Power Dissipation, measured in picojoules (pJ).
