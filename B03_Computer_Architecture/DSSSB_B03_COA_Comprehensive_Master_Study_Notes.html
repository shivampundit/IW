Von Neumann vs Harvard Architecture Comparison

Von Neumann Model (Stored-Program)

• Single physical memory and common bus for both instructions and data.
• Bottleneck: Cannot fetch instruction and read/write data simultaneously.
• Simpler hardware design; used in general-purpose desktop computing.

Harvard Architecture

• Physically separate memories and buses for instructions and data.
• Parallel access: CPU can fetch an instruction while accessing memory data.
• High throughput; standard in DSPs and modern CPU L1 caches (split L1i / L1d).

Memory Hierarchy, Cache Mapping & DRAM/SRAM Physics

Access time hierarchy, Direct vs Fully-Associative vs Set-Associative mapping, Write policies, and Locality of Reference.

Direct Mapping

Block j of main memory maps to cache line: i = j mod (Number of Lines).
Pros: Simplest, fastest lookup.
Cons: High conflict miss rate.

Fully Associative

Any memory block can be placed in ANY cache line.
Address divided into: Tag + Block Offset.
Pros: Zero conflict misses.
Cons: Expensive parallel comparators.

k-way Set-Associative

Cache divided into sets of k lines: Set index = j mod (Sets).
Tag + Set Index + Word Offset.
Best engineering compromise!

Effective Memory Access Time (EMAT) Formula

EMAT = H * T_c + (1 - H) * (T_c + T_m)

Where H = Cache Hit Ratio, T_c = Cache Access Time, T_m = Main Memory Access Time. (If simultaneous access: EMAT = H * T_c + (1 - H) * T_m).

Pipelining Speedup Formulas
Total Cycles for n instructions in k-stage pipe: k + (n - 1)
Speedup (S) = (Non-pipelined time) / (Pipelined time)
S = (n * k) / (k + n - 1)
For very large n (n -> ∞): Maximum Speedup S_max = k
Efficiency (η) = Speedup / k = n / (k + n - 1)
Pipeline Hazards & Solutions

• Structural Hazard: Hardware conflict (e.g., single memory port). Solution: Separate instruction and data caches.
• Data Hazard (RAW): Instruction needs data before prior instruction writes it. Solution: Operand Forwarding (bypassing).
• Control Hazard (Branch): Branch changes PC. Solution: Branch Prediction, Delayed Branching with compiler delay slots.

Programmed I/O vs Interrupts vs DMA, Cycle Stealing, Daisy-Chaining arbitration, and RAID levels 0 through 6.

DMA Transfer Modes

• Cycle Stealing: DMA borrows one bus cycle from CPU to transfer a single word, then returns bus.
• Burst Mode: DMA seizes bus and transfers the entire block continuously.
• Transparent Mode: DMA transfers data only when CPU is executing internal decode/ALU cycles without using the bus.

RAID Levels Summary

• RAID 0: Striping without redundancy (High performance, 0 fault tolerance).
• RAID 1: Mirroring (100% redundancy, 50% storage efficiency).
• RAID 3: Byte striping with dedicated parity disk.
• RAID 5: Block striping with Distributed Parity (Tolerates 1 drive failure).
• RAID 6: Dual distributed parity (Tolerates 2 simultaneous drive failures).
