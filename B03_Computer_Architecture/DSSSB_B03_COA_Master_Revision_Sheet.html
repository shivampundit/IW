Computer Architecture — 30 Golden Formulas & Memory Cheat Sheet

EMAT access formulas, pipeline speedup equations, addressing modes matrix, and cache mapping cheat sheet.

Cache: EMAT Formula

EMAT = H * T_c + (1 - H) * (T_c + T_m).
Simultaneous: EMAT = H * T_c + (1 - H) * T_m.

Pipeline: Total Cycles

Total Cycles = k + (n - 1) for n instructions in k stages.
Max speedup S_max = k (as n -> ∞).

IEEE-754: Bias Form

Single (32-bit): 1 Sign + 8 Exp + 23 Mantissa (Bias 127).
Double (64-bit): 1 Sign + 11 Exp + 52 Mantissa (Bias 1023).

Amdahl's Law Speedup

Speedup = 1 / ((1 - f) + f / s).
If f is fraction enhanced by factor s. Max speedup = 1 / (1 - f).

Cache: Set-Associative

Sets = Lines / k.
Address format: Tag bits + Set-index bits + Word-offset bits.

Registers: PC vs MAR

PC: Holds address of NEXT instruction.
MAR: Holds address of CURRENT memory access.

RAM: DRAM vs SRAM

DRAM: 1T+1C (requires periodic refresh).
SRAM: 6T flip-flop (no refresh, faster, cache).

DMA: Cycle Stealing

DMA steals 1 bus cycle to transfer 1 word, then releases bus back to CPU.

RAID: Redundancy Levels

RAID 0: 0 fault tolerance.
RAID 1: Mirroring.
RAID 5: Distributed parity (1 drive fail).

1. First generation used vacuum tubes; second used transistors; third used integrated circuits; fourth used VLSI microprocessors.
2. ENIAC (1946) was the first general-purpose electronic digital computer.

4. Moore's Law predicts transistor count on ICs doubles approximately every two years.
5. Temporal Locality: recently accessed items are likely to be accessed again; Spatial Locality: nearby items are accessed soon.
6. Write-Through writes to cache and RAM simultaneously; Write-Back writes to RAM only when block is evicted.
7. Direct mapping has the highest conflict misses; Fully associative has zero conflict misses.
8. Hardwired control units are faster (combinational logic); Microprogrammed are flexible (ROM micro-routines).
9. The Address Bus is strictly unidirectional (CPU to Memory/IO); the Data Bus is bidirectional.
10. In a downward-growing stack, PUSH decrements SP before writing data.
11. Program relocation is implemented via Base-Register addressing: EA = [Base] + Offset.
12. In Register Indirect mode, the register holds the memory address of the operand.
13. In IEEE-754: Exponent all 1s and Mantissa 0 represents Infinity; Exponent all 1s and Mantissa non-zero is NaN.
14. Standard 7-bit ASCII has 128 characters ('A'=65, 'a'=97, '0'=48); Extended 8-bit has 256 characters.
15. UTF-8 uses variable length encoding from 1 to 4 bytes.
16. In Little Endian, the Least Significant Byte (LSB) is stored at the lowest memory address.
17. Structural hazards occur due to hardware resource conflicts; resolved by separate I-cache and D-cache.
18. Read-After-Write (RAW) data hazards are eliminated using Operand Forwarding (Bypassing).
19. In Vectored interrupts, the interrupting peripheral provides the starting address of its ISR directly.
20. In Memory-Mapped I/O, I/O ports share the memory address space and use standard MOV/ADD instructions.
