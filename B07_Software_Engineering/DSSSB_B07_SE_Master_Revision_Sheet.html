Software Engineering — 30 Golden Rules & Testing Cheat Sheet

Coupling-cohesion spectrum, McCabe's complexity, COCOMO formulas, and CMM maturity levels.

Architecture: Golden Rule

Low (Loose) Coupling and High (Strong) Cohesion for clean modular software.

Coupling: Best to Worst

Data < Stamp < Control < Common < Content Coupling (Worst).

Cohesion: Best to Worst

Functional (Best) > Sequential > Communicational > Procedural > Temporal > Logical > Coincidental (Worst).

Testing: McCabe's V(G)

V(G) = E - N + 2P.
Also = Predicate Nodes + 1 = Enclosed Regions + 1.

COCOMO: Effort Formula

Effort E = a * (KLOC)^b.
Organic: a=2.4, b=1.05; Embedded: a=3.6, b=1.20.

Risk: Exposure Formula

Risk Exposure = P * C (Probability of occurrence * Cost of impact).

CMM: 5 Maturity Levels

1. Initial ➔ 2. Repeatable ➔ 3. Defined ➔ 4. Managed ➔ 5. Optimizing.

Maintenance: Breakdown

Perfective (~50-60%) > Adaptive (~25%) > Corrective (~20%) > Preventive (~5%).

Integration: Scaffolding

Top-Down: uses Stubs.
Bottom-Up: uses Drivers.

20 Golden Exam One-Liners (Quick Revision)

1. Spiral model is risk-driven and includes explicit Risk Analysis at each iteration.
2. In the V-model, Requirements Analysis maps directly to User Acceptance Testing (UAT).
3. Verification checks 'Are we building the product right?'; Validation checks 'Are we building the right product?'.
4. IEEE 830-1998 is the international standard governing Software Requirements Specifications (SRS).
5. A Context Diagram (Level-0 DFD) represents the entire system as a single Process 0.
6. In DFDs, flows between two external entities or between two data stores are strictly illegal.
7. Data Coupling is the best coupling; Content Coupling is the worst.
8. Functional Cohesion is the best cohesion; Coincidental Cohesion is the worst.
9. Common coupling occurs when modules share global data variables.
10. Boundary Value Analysis (BVA) tests: min-1, min, min+1, max-1, max, max+1.
11. Cyclomatic complexity V(G) defines the minimum number of basis path test cases.
12. Regression testing verifies that code modifications did not introduce bugs into existing features.
13. Alpha testing is done by internal staff at developer's site; Beta testing is done by real users at user sites.
14. Perfective maintenance (feature enhancements) consumes ~50-60% of lifetime maintenance effort.
15. Function Points are programming language independent, unlike Lines of Code (SLOC).
16. The 5 CMM levels are: Initial, Repeatable, Defined, Managed, and Optimizing.
17. Human Error leads to program Fault (Bug), which triggers runtime Failure.
18. Cleanroom software engineering emphasizes formal verification for zero-defect software.
19. In Agile Scrum, Sprints are fixed 2 to 4 week time-boxed iterations.
20. Information Hiding (Parnas) conceals internal data representations behind clean interfaces.
