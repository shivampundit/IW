Verification vs Validation (Boehm's Axiom)

• Verification: 'Are we building the product right?' Static analysis (code inspections, reviews, walkthroughs) ensuring specifications are strictly adhered to.
• Validation: 'Are we building the right product?' Dynamic execution of software to ensure it satisfies real customer business expectations.

IEEE 830 SRS Quality Characteristics

• Correct: Every requirement aligns with user needs.
• Unambiguous: Every requirement has exactly ONE interpretation.
• Complete: Includes all functional, behavioral, and non-functional requirements.
• Verifiable (Testable): A cost-effective test can definitively pass or fail it.
• Consistent: No internal contradictions between requirements.
• Modifiable & Traceable: Easy to change with RTM mapping.

Functional vs Non-Functional Requirements

• Functional Requirements: Describe what the system MUST do (e.g., 'User can deposit money', 'Generate monthly PDF invoice').
• Non-Functional Requirements (NFRs): Describe operational quality constraints (e.g., 'Response time < 1.5s', '99.99% system availability', 'AES-256 data encryption').

DFD Hierarchy & Syntax Rules

Coupling Hierarchy (Best to Worst)
  1. Data Coupling (Best): Communication strictly via scalar data arguments.
  2. Stamp Coupling: Passing complex records where only partial fields are used.
  3. Control Coupling: One module passes flags dictating control flow of another.
  4. Common Coupling: Multiple modules share global data variables.
  5. Content Coupling (Worst): One module modifies private code/data of another directly.
Cohesion Hierarchy (Best to Worst)
  1. Functional Cohesion (Best): All elements perform a single mathematical/logical task.
  2. Sequential Cohesion: Output of one step is input to next.
  3. Communicational Cohesion: Operations operate on same input/output dataset.
  4. Procedural Cohesion: Operations executed in specific sequence.
  5. Temporal Cohesion: Tasks executed at same time (e.g., startup).
  6. Logical Cohesion: Related by broad category (e.g., all math functions).
  7. Coincidental Cohesion (Worst): Arbitrary grouping with no relation.
