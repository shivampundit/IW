Raster vs Random (Vector) Scan

• Raster Scan: Electron beam sweeps sequentially row-by-row across the entire screen from top to bottom (horizontal/vertical retrace), reading pixel values from a Frame Buffer (60–120 Hz refresh rate).
• Random Scan (Vector/Stroke): Beam is directed only to the coordinates where lines are drawn, acting like an electron pen plotter. High resolution without pixel jaggies; no frame buffer needed.

Frame Buffer Memory Formula
Memory = (Width * Height * Bits per Pixel) / 8 bytes
• 1024 x 768 @ 24-bit True Color:
Total Bytes = 1024 * 768 * 3 = 2,359,296 bytes = 2.25 MB

Z-Buffer depth tests, Painter's back-to-front depth sort, Back-Face culling, A-Buffer, and BSP trees.

Z-Buffer (Depth-Buffer) Algorithm

• Image-space algorithm with $O(width imes height)$ memory.
• Stores closest depth $z$ per pixel (initialized to $\infty$).
• If new surface point has $z < ext{depth}(x, y)$, updates color buffer and records new closer $z$.
• A-Buffer: Extends Z-buffer with linked list of transparent fragments per pixel.

Object-Space Visibility Algorithms

• Back-Face Culling: Discards polygon faces pointing away from viewer if $\mathbf{N} \cdot \mathbf{V} < 0$, eliminating ~50% of geometric workload.
• Painter's Algorithm: Sorts polygons by depth and paints from farthest to nearest (back to front). Fails on cyclic overlaps.
• BSP Tree: Prepartitions space into half-spaces for linear-time depth sorting.
