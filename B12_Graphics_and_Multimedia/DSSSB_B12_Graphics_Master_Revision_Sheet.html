Computer Graphics & Multimedia — 30 Golden Rules Cheat Sheet

Bresenham decision parameters, Cohen-Sutherland clipping codes, Z-buffer rules, and JPEG/MPEG compression pipelines.

Bresenham: Integer Math

Line: p0 = 2Δy - Δx.
Circle: p0 = 1 - r.
Zero floating-point rounding errors!

Clipping: Cohen-Sutherland

Inside = 0000.
Trivial Accept: code1 | code2 == 0000.
Trivial Reject: (code1 & code2) != 0000.

Transform: Homogeneous

2D uses 3x3 matrices; 3D uses 4x4.
Unifies translation as matrix multiplication.

Z-Buffer: Image-Space

Updates pixel color and depth if new z is closer: z < depth(x, y).
A-Buffer handles transparency.

Culling: Back-Face Test

Discards polygons pointing away from camera if N · V < 0 (~50% geometry reduction).

Shading: Gouraud vs Phong

Gouraud: interpolates vertex colors (Mach bands).
Phong: interpolates normals per pixel (specular).

Curves: Bézier Bernstein

Bézier satisfies Convex Hull Property.
B-Splines offer local control.

Compression: JPEG DCT

8x8 blocks ➔ Discrete Cosine Transform ➔ Quantization (lossy) ➔ Huffman coding.

Audio: Nyquist Sampling

fs >= 2 * f_max.
CD Audio uses 44.1 kHz. MIDI stores event commands, not audio waveforms.

16. The Phong illumination model combines: Ambient + Diffuse (Lambert) + Specular reflection.
