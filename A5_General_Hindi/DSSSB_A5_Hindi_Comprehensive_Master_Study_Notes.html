काल (Tense) के 14 उपभेद — भूतकाल (6), वर्तमान काल (5) एवं भविष्यत् काल (3)भूतकाल के 6 भेद: सामान्य • आसन्न (अभी समाप्त: 'है' लगा हो) • पूर्ण ('था/थी/थे') • अपूर्ण ('रहा था') • संदिग्ध ('होगा') • हेतुहेतुमद्भूत (शर्त: 'यदि...तो')DSSSB सामान्य हिन्दी में 'काल' और 'वाच्य' से सर्वाधिक प्रश्न पूछे जाते हैं: (1) आसन्न भूतकाल: क्रिया अभी-अभी समाप्त हुई हो ('मैंने आम खाया है' — दिखने में 'है' लगता है पर कार्य पूर्ण होने के कारण आसन्न भूतकाल है!); (2) संदिग्ध वर्तमान ('माँ खाना बना रही होगी') बनाम संदिग्ध भूतकाल ('उसने खाना खाया होगा'); (3) हेतुहेतुमद्भूत ('यदि वर्षा होती तो फसल अच्छी होती' — भूतकाल की शर्त) बनाम हेतुहेतुमद्भविष्यत् ('यदि तुम पढ़ोगे तो पास हो जाओगे' — भविष्य की शर्त)।Exam Trap: 'मैंने खाना खाया है' में अंत में 'है' देखकर वर्तमान काल मत लगा देना — क्रिया अभी-अभी पूर्ण हुई है इसलिए यह 'आसन्न भूतकाल' (Recent Past) है!
काल एवं वाच्य — Core Principle #1: भाववाच्यVerified Rule / Benchmark: भाववाच्यQuestion Context: 'मुझसे अब चला नहीं जाता।' इस वाक्य में कौन-सा वाच्य प्रयुक्त हुआ है? — Technical Explanation: भाववाच्य की पहचान: क्रिया का लिंग, वचन और पुरुष कर्ता या कर्म के अनुसार न होकर हमेशा पुल्लिंग, एकवचन तथा अन्य पुरुष में रहता है। यह प्रायः अकर्मक क्रियाओं से बनता है और असमर्थता/विवशता प्रकट करता है ('मुझसे चला नहीं जाता', 'रोगी से उठा नहीं जाता')।Hinglish Tip / Memory Hook: अकर्मक क्रिया + असमर्थता का भाव = भाववाच्य। | Common Distractor Traps to Avoid: कर्तृवाच्य; कर्मवाच्य.
काल एवं वाच्य — Core Principle #2: कर्मवाच्यVerified Rule / Benchmark: कर्मवाच्यQuestion Context: 'अध्यापक द्वारा छात्रों को कंप्यूटर विज्ञान पढ़ाया गया।' यह किस वाच्य का उदाहरण है? — Technical Explanation: कर्मवाच्य: जब वाक्य में क्रिया का लिंग और वचन कर्ता के अनुसार न होकर 'कर्म' के अनुसार निर्धारित होता है, तथा कर्ता के साथ 'के द्वारा' या 'द्वारा' कारक चिह्न लगा हो, तो कर्मवाच्य होता है। यहाँ 'पढ़ाया गया' सकर्मक क्रिया है और कर्म 'कंप्यूटर विज्ञान' मुख्य है।Hinglish Tip / Memory Hook: सकर्मक क्रिया + 'के द्वारा' = कर्मवाच्य। | Common Distractor Traps to Avoid: कर्तृवाच्य; भाववाच्य.
काल एवं वाच्य — Core Principle #3: हेतुहेतुमद् भूतकालVerified Rule / Benchmark: हेतुहेतुमद् भूतकालQuestion Context: 'यदि वर्षा होती, तो फसल अच्छी होती।' यह वाक्य भूतकाल के किस भेद के अंतर्गत आता है? — Technical Explanation: हेतुहेतुमद् भूतकाल: जहाँ भूतकाल की एक क्रिया दूसरी क्रिया पर निर्भर हो (कारण-कार्य संबंध हो), किन्तु कारण के अभाव में कार्य न हो सका हो। 'यदि वर्षा होती (कारण), तो फसल अच्छी होती (कार्य)'।Hinglish Tip / Memory Hook: शर्त या कारण-कार्य संबंध = हेतुहेतुमद् भूतकाल। | Common Distractor Traps to Avoid: आसन्न भूतकाल; संदिग्ध भूतकाल.
काल एवं वाच्य — Core Principle #4: संदिग्ध वर्तमानकालVerified Rule / Benchmark: संदिग्ध वर्तमानकालQuestion Context: 'मोहन पत्र लिख रहा होगा।' इस वाक्य में कौन-सा काल है? — Technical Explanation: संदिग्ध वर्तमानकाल: क्रिया के जिस रूप से वर्तमान में कार्य के होने में संदेह प्रकट हो (धातु + रहा होगा / ता होगा / ती होगी)। 'लिख रहा होगा' वर्तमान काल में कार्य की अनिश्चितता दर्शाता है।Hinglish Tip / Memory Hook: 'रहा होगा / ता होगा' = संदिग्ध वर्तमानकाल। | Common Distractor Traps to Avoid: सामान्य वर्तमानकाल; तात्कालिक वर्तमानकाल.
काल एवं वाच्य — Core Principle #5: सुनीता ने सुंदर गीत गाया।Verified Rule / Benchmark: सुनीता ने सुंदर गीत गाया।Question Context: कर्तृवाच्य वाक्य का चयन कीजिए: — Technical Explanation: कर्तृवाच्य: जिस वाक्य में कर्ता मुख्य हो और क्रिया का सीधा संबंध कर्ता से हो। 'सुनीता ने सुंदर गीत गाया' में कर्ता 'सुनीता' प्रधान है। शेष वाक्यों में कर्मवाच्य (किसानों द्वारा, मेरे द्वारा) और भाववाच्य (दादी जी से...) हैं।Hinglish Tip / Memory Hook: कर्ता की प्रधानता वाला वाक्य कर्तृवाच्य होता है। | Common Distractor Traps to Avoid: किसानों द्वारा खेत जोते गए।; दादी जी से सीढ़ियाँ नहीं चढ़ी जातीं।.

काल एवं वाच्य — Core Principle #7: भाववाच्य का निर्माण सकर्मक क्रियाओं से होता है।Verified Rule / Benchmark: भाववाच्य का निर्माण सकर्मक क्रियाओं से होता है।Question Context: भाववाच्य के संदर्भ में कौन-सा कथन असत्य है? — Technical Explanation: असत्य कथन C है। भाववाच्य का निर्माण सदैव 'अकर्मक क्रिया' (Intransitive Verbs) से होता है (जैसे: चलना, बैठना, सोना, हँसना)। सकर्मक क्रियाओं से कर्मवाच्य बनता है। भाववाच्य में क्रिया सदैव अकर्मक, एकवचन, पुल्लिंग और अन्य पुरुष होती है।Hinglish Tip / Memory Hook: भाववाच्य अकर्मक क्रिया से बनता है, सकर्मक से नहीं। | Common Distractor Traps to Avoid: भाववाच्य में क्रिया सदैव एकवचन होती है।; भाववाच्य में क्रिया सदैव पुल्लिंग होती है।.
काल एवं वाच्य — Core Principle #8: संभाव्य भविष्यत्Verified Rule / Benchmark: संभाव्य भविष्यत्Question Context: 'शायद कल दिल्ली में भारी वर्षा हो।' यह वाक्य भविष्यत्काल के किस भेद का उदाहरण है? — Technical Explanation: संभाव्य भविष्यत्काल: जहाँ आने वाले समय में किसी कार्य के होने की संभावना या इच्छा प्रकट की जाए ('शायद', 'हो सकता है')।Hinglish Tip / Memory Hook: 'शायद' शब्द आने पर संभाव्य भविष्यत्काल होता है। | Common Distractor Traps to Avoid: सामान्य भविष्यत्; हेतुहेतुमद् भविष्यत्.
काल एवं वाच्य — Core Principle #9: अपूर्ण भूतकाल (तात्कालिक भूत)Verified Rule / Benchmark: अपूर्ण भूतकाल (तात्कालिक भूत)Question Context: 'माली पौधों को पानी दे रहा था।' इस वाक्य में काल है: — Technical Explanation: अपूर्ण भूतकाल: जहाँ भूतकाल में कार्य प्रारंभ तो हो चुका था, किन्तु समाप्त होने का बोध न हो (रहा था, रही थी, रहे थे)।Hinglish Tip / Memory Hook: 'रहा था/रही थी' = अपूर्ण भूतकाल। | Common Distractor Traps to Avoid: पूर्ण भूतकाल; सामान्य भूतकाल.
काल एवं वाच्य — Core Principle #10: पक्षियों से आकाश में उड़ा जाता है।Verified Rule / Benchmark: पक्षियों से आकाश में उड़ा जाता है।Question Context: कर्तृवाच्य वाक्य 'पक्षी आकाश में उड़ते हैं' को भाववाच्य में परिवर्तित कीजिए: — Technical Explanation: भाववाच्य रूपांतरण नियम: कर्ता के साथ 'से' जोड़ें + मुख्य क्रिया को सामान्य भूतकाल में बदलकर उसके साथ 'जाना' धातु का एकवचन पुल्लिंग रूप जोड़ें: 'पक्षियों से आकाश में उड़ा जाता है'।Hinglish Tip / Memory Hook: कर्ता + 'से' + क्रिया का 'जाता है' रूप = भाववाच्य। | Common Distractor Traps to Avoid: पक्षी आकाश में उड़ सकते हैं।; पक्षियों द्वारा आकाश में उड़ा गया था।.

  • 2. गुण संधि (आद्गुणः): अ/आ + इ/ई = ए; अ/आ + उ/ऊ = ओ; अ/आ + ऋ = अर्। उदा: नर + इंद्र = नरेंद्र, सूर्य + उदय = सूर्योदय, महा + ऋषि = महर्षि।
  • 3. वृद्धि संधि (वृद्धिरेचि): अ/आ + ए/ऐ = ऐ; अ/आ + ओ/औ = औ। उदा: एक + एक = एकैक, महा + ओज = महौज, मत + ऐक्य = मतैक्य।
  • 4. यण् संधि (इको यणचि): इ/ई + असमान स्वर = य्; उ/ऊ + असमान स्वर = व्; ऋ + असमान स्वर = र्। उदा: यदि + अपि = यद्यपि, इति + आदि = इत्यादि, अनु + अय = अन्वय, सु + आगत = स्वागत, पितृ + आज्ञा = पित्राज्ञा।
  • 5. अयादि संधि (एचोऽयवायावः): ए + स्वर = अय्; ऐ + स्वर = आय्; ओ + स्वर = अव्; औ + स्वर = आव्। उदा: ने + अन = नयन, गै + अक = गायक, पो + अन = पवन, पौ + अक = पावक, नौ + इक = नाविक।
