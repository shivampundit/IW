HTTP Protocols, Web Servers & Client-Server Architecture

GET vs POST, HTTP status codes, MIME types, Reverse Proxies (NGINX), and HTTP/2 multiplexing.

HTTP Request Methods
• GET: Appends query parameters to URL; idempotent, cacheable, bookmarked; not secure for credentials.
• POST: Transmits data inside message body; not cached; used for state creation & passwords.
• PUT: Completely replaces target resource; idempotent.
• PATCH: Partially updates target resource.
• DELETE: Removes target resource; idempotent.
HTTP Status Code Series
• 2xx (Success): 200 OK, 201 Created, 204 No Content
• 3xx (Redirection): 301 Moved Permanently, 304 Not Modified
• 4xx (Client Error): 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 405 Method Not Allowed
• 5xx (Server Error): 500 Internal Server Error, 502 Bad Gateway, 503 Service Unavailable, 504 Gateway Timeout

Scoping & Closures

• var: Function-scoped; hoisted to top and initialized to undefined.
• let / const: Block-scoped (`{}`); hoisted into Temporal Dead Zone (TDZ); cannot be accessed before declaration.
• Closure: An inner function that retains access to its enclosing lexical scope variables even after the outer function has completed execution.

DOM Event Propagation Phases

1. Capturing Phase (Trickling): Window ➔ Document ➔ Body down to Target element.

3. Bubbling Phase: Bubbles up from Target element back to Window.

Web Attacks & Defenses
• XSS (Cross-Site Scripting): Injected malicious JavaScript runs in victim's browser. Mitigated by HTML encoding, CSP, and HttpOnly cookie flag (prevents JS access).
• CSRF (Cross-Site Request Forgery): Tricks authenticated browser into sending unauthorized requests. Mitigated by Anti-CSRF Tokens and SameSite=Strict cookie flag.
Browser Storage Options
• Cookies (4 KB): Sent with every HTTP request. Used for session IDs.
• localStorage (~5-10 MB): Permanent key-value string storage on disk.
• sessionStorage (~5 MB): Scoped to current browser tab; deleted on tab close.
• SOP & CORS: Same-Origin requires matching Protocol, Host, Port. CORS uses Access-Control-Allow-Origin.
