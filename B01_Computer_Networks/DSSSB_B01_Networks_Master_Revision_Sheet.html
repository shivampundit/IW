🎯 25 Golden One-Liners (Direct DSSSB Repeats) Read 2 times

  1. Ethernet Framing: Standard Ethernet (IEEE 802.3) frame ka minimum size 64 bytes aur maximum size 1518 bytes hota hai.
  2. Preamble: Ethernet preamble 7 bytes (56 bits) ka alternating 10101010 pattern hota hai jo receiver clock synchronize karta hai; iske baad 1 byte ka SFD (Start Frame Delimiter: 10101011) aata hai.
  3. MAC Address: 48 bits (6 bytes) ka hota hai, hexadecimal me likha jata hai (e.g. 00:1A:2B:3C:4D:5E). Pehle 24 bits OUI (Manufacturer ID) hote hain aur aakhiri 24 bits Device NIC ID hote hain.
  4. IP Header Size: IPv4 header ka minimum size 20 bytes aur maximum size 60 bytes hota hai (HLEN field = 5 to 15, multiplied by 4).
  5. TCP Header Size: TCP header bhi minimum 20 bytes aur maximum 60 bytes ka hota hai.
  6. UDP Header Size: Fixed 8 bytes ka hota hai (4 fields of 2 bytes each: Source Port, Dest Port, Total Length, Checksum).
  7. IPv6 Base Header: Fixed 40 bytes ka hota hai. Isme checksum field nahi hoti.
  8. Collision Domain Breakdown: Hub collision domain divide nahi karta; Switch har port par collision domain divide karta hai; Router collision aur broadcast domain dono ko divide karta hai.
  9. CSMA/CD: Collision Detection Wired Ethernet me use hota hai. Agar collision detect ho jaye to Jam Signal bheja jata hai aur Binary Exponential Backoff algorithm execute hota hai.
  10. CSMA/CA: Collision Avoidance Wireless Wi-Fi (802.11) me use hota hai kyunki wireless transceiver ek sath transmit aur listen (detect) nahi kar sakta. Uses RTS/CTS (Request to Send / Clear to Send).
  11. Address Resolution Protocol (ARP): Logical 32-bit IP address ko Physical 48-bit MAC address me translate karta hai. ARP Request is Broadcast, ARP Reply is Unicast.
  12. RARP & BOOTP: Physical MAC address se IP address pata karne ke liye use hote the (now replaced by DHCP).
  13. ICMP (Internet Control Message Protocol): Network layer protocol hai jo error reporting aur diagnostic testing (Ping, Traceroute) ke liye use hota hai. Ping utility ICMP Echo Request (Type 8) aur Echo Reply (Type 0) use karti hai.
  14. TTL (Time to Live): IP header me 8-bit field hoti hai jo packet ko routing loops me infinite ghumne se rokti hai. Har router par TTL 1 kam hota hai; jab TTL = 0 ho jata hai, router packet drop karke ICMP Time Exceeded (Type 11) bhejta hai.
  15. Loopback IP: 127.0.0.1 (any 127.x.x.x) internal TCP/IP protocol stack test karne ke liye use hota hai. Ye packet kabhi network wire par transmit nahi hota.
  16. APIPA Range: 169.254.0.1 se 169.254.255.254 tak hoti hai (Subnet mask 255.255.0.0). Jab DHCP fail ho jaye to Windows OS khud ye IP assign karta hai.
  17. BGP (Border Gateway Protocol): Autonomous Systems (AS) ke beech routing ke liye Path Vector Protocol hai, jo TCP port 179 par chalta hai. Internet ka main backbone protocol hai.
  18. OSPF (Open Shortest Path First): Intra-domain Link State Protocol hai jo Dijkstra's Algorithm (SPF) use karta hai. IP protocol number 89 use karta hai (no transport layer).
  19. RIP (Routing Information Protocol): Intra-domain Distance Vector Protocol hai jo Bellman-Ford Algorithm aur metric ke roop me Hop Count (Maximum 15 hops; 16 = Infinity/Unreachable) use karta hai. Uses UDP port 520.
  20. RSA Algorithm: Asymmetric public key cryptography algorithm hai jo badi prime numbers ke factorization ki mathematical difficulty par aadharit hai.
  21. Diffie-Hellman: Insecure channel par do parties ke beech symmetric secret key exchange karne ka algorithm hai. Discrete Logarithm problem par aadharit hai.
  22. Digital Signature Key Rule: Message sender apni Private Key se sign karta hai, aur koi bhi receiver sender ki Public Key se signature verify karta hai.
  23. Encryption for Privacy: Agar Alice ko Bob ko secret message bhejna hai to Alice use Bob ki Public Key se encrypt karegi, aur sirf Bob hi use apni Private Key se decrypt kar sakega.
  24. Firewall Types: Packet Filter firewall Layer 3/4 par kaam karta hai; Application Gateway / Proxy firewall Layer 7 par deep inspection karta hai.
  25. Network Cable Standard: T568B color coding standard me pair sequence: White-Orange, Orange, White-Green, Blue, White-Blue, Green, White-Brown, Brown hota hai.
