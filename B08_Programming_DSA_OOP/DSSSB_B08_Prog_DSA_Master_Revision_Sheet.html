Programming, Data Structures & OOP — 30 Golden Rules Cheat Sheet

C pointer arithmetic, stack/queue conditions, BST traversals, OOP dynamic binding, and Java/Python rules.

C: Array Equivalence

arr[i] == *(arr + i).
In C, sizeof('A') is 4 bytes (int); in C++ it is 1 byte (char).

Queue: Circular FULL

Condition: (rear + 1) % N == front.
EMPTY condition: front == -1.

List: Floyd's Cycle

Slow pointer (1 step) + Fast pointer (2 steps). Collide inside cycle in O(n) time and O(1) space.

Tree: Strict Binary Nodes

Leaf nodes L = Internal nodes I + 1.
Max nodes at height h = 2^(h+1) - 1.

BST: Inorder Property

Inorder traversal (Left ➔ Root ➔ Right) on a BST strictly produces sorted ascending order.

OOP: Virtual Destructor

Always declare base destructor virtual so derived class destructor executes, preventing memory leaks.

Java: Strings == vs .equals

== checks reference memory address; .equals() checks character contents.

Python: Immutable Types

Immutable: int, float, str, tuple.
Mutable: list, dict, set.

Python: LEGB Scope

Namespace resolution: Local ➔ Enclosing ➔ Global ➔ Built-in.
