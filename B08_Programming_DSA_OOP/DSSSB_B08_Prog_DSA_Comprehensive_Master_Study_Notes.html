Pointer arithmetic, dangling pointers, storage classes (auto, static, extern, register), struct vs union.

Storage Classes Matrix
• auto: Default on stack; destroyed upon function exit.
• static: Initialized once in data segment (default 0); retains value across calls; local scope.
• extern: Declares variable defined in another translation unit; global lifetime.
• register: Request to store in CPU register; no address-of operator (&) permitted.
Pointer Traps & Array Arithmetic
• Array Equivalence: arr[i] == *(arr + i) == *(i + arr) == i[arr]
• Dangling Pointer: Points to deallocated/freed heap memory or returned stack frame address.
• Memory Size: sizeof('A') is 4 bytes (int) in C, but 1 byte (char) in C++!
• Union: Size equals largest member; all members share address 0.

Singly, Doubly, Circular linked lists, in-place list reversal, and Tortoise-Hare cycle detection.

Floyd's Tortoise and Hare Cycle Detection

Two pointers traverse the list: slow advances 1 node per step, fast advances 2 nodes per step. If a loop exists, the relative speed difference decreases the distance between them by 1 node per iteration, guaranteeing they collide inside the cycle in O(n) time and O(1) space. To find the loop start: reset slow = head and advance both by 1 step; they will meet at the loop entrance!

In-Place List Reversal (3 Pointers)

prev = NULL; curr = head;
while(curr) {
  next = curr->next;
  curr->next = prev;
  prev = curr; curr = next;
}
head = prev;

Doubly & Circular List Properties

• Doubly Linked List: Node insertion between two nodes takes 4 pointer updates.
• Circular List: Last node points back to head instead of NULL.
• Random Access: Linked lists lack O(1) indexing; Binary Search cannot run in O(log n).
